Federated Learning + Edge–Cloud Hybrid
Patient data never leaves the edge device. Local models train on each device, and only encrypted gradient updates are shared with the hospital gateway. The cloud server runs FedAvg to produce a global model, which is broadcast back to all nodes. Zero raw data exposure.
